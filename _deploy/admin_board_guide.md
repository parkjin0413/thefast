# 관리자 화면에서 게시판 직접 만들기 (DB 접근 없이)

`setup_boards.sql` 을 실행할 수 없을 때, 그누보드 관리자 화면에서 같은 결과를 만드는 방법입니다.
항목 이름은 그누보드 5.6 기준이며, 버전에 따라 조금 다를 수 있습니다.

권한 숫자: **1 = 비회원(누구나)**, 2 = 일반회원, **10 = 최고관리자**

---

## 0단계. 테마 적용 확인 (1회)

1. **환경설정 > 테마설정** 에서 "더패스트 THE FAST" 의 **테마적용** 클릭
2. "기본 스킨도 적용할까요?" 확인창이 나오면 **확인** → FAQ 스킨이 테마 것으로 바뀝니다.
3. **환경설정 > 기본환경설정** 에서 확인
   - 홈페이지 제목: `더패스트`
   - **FAQ 스킨**: `(테마) thefast` 인지 확인 (아니면 선택 후 저장)

## 1단계. 게시판 만들기

**게시판관리 > 게시판관리 > 게시판 추가** 에서 아래 표대로 하나씩 만듭니다.

- **TABLE(게시판 ID)은 영문 소문자로 정확히** 입력하세요. 테마 메뉴가 이 ID 로 연결됩니다.
- **그룹**은 설치 때 기본으로 있는 그룹(커뮤니티)을 선택하면 됩니다.
- **접속기기**: PC와 모바일 모두
- **스킨 디렉토리**와 **모바일 스킨 디렉토리**를 **둘 다 같은 스킨**으로 고르세요. (테마 스킨은 이름 앞에 `(테마)` 가 붙어 있습니다)
- 표에 없는 항목은 기본값 그대로 두세요.

### 만들 게시판 7개 (위에서부터 중요한 순서)

| TABLE | 게시판 제목 | 스킨 (PC·모바일 동일) | 분류 |
|---|---|---|---|
| `inquiry` | 상담 문의 | (테마) thefast_form | 사용 안 함 |
| `portfolio` | 시공사례 | (테마) thefast_gallery | **사용** · `주거공간\|관공서\|상업시설\|기타시공` |
| `review` | 고객 후기 | (테마) thefast_gallery | 사용 안 함 |
| `news` | 더패스트 소식 | (테마) thefast_list | 사용 안 함 |
| `history` | 주요 실적 | (테마) thefast_list | 사용 안 함 |
| `event` | 리뷰 이벤트 | (테마) thefast_list | 사용 안 함 |
| `partner` | 제휴 문의 | (테마) thefast_form | 사용 안 함 |

> 시공사례 분류는 `|` (세로줄) 로 구분합니다. 분류 이름은 자유롭게 바꿔도 메뉴가 자동으로 따라갑니다.
> (예: 주거 중심이면 `욕실|주방|거실·아트월|전체 리모델링` 도 가능)

### 게시판별 권한·기능 설정

**[게시판 권한 설정]**

| 항목 | inquiry · partner | portfolio · news · history · event | review |
|---|---|---|---|
| 목록보기 권한 | 1 | 1 | 1 |
| 글읽기 권한 | 1 | 1 | 1 |
| 글쓰기 권한 | **1** (고객이 신청) | **10** (관리자만) | 1 (고객 작성) 또는 10 |
| 글답변 권한 | 10 | 10 | 10 |
| 댓글쓰기 권한 | **10** (답변은 관리자 댓글로) | 10 | 10 |
| 업로드 권한 | 1 | 10 | 1 |

**[게시판 기능 설정]**

| 항목 | inquiry · partner | portfolio · news · history · event | review |
|---|---|---|---|
| 비밀글 사용 | **무조건** | 사용하지 않음 | 사용하지 않음 |
| DHTML 에디터 사용 | **체크 해제** | 체크 (사진 넣기 편함) | 체크 해제 |
| 캡챠 사용 | 체크 | 해제 | 체크 |
| 메일발송 사용 | 체크 (문의 오면 메일 알림) | 해제 | 해제 |
| 파일 업로드 개수 | 3 | portfolio 20 / 나머지 5 | 5 |
| 파일 업로드 용량 | 10485760 (=10MB) | 10485760 | 10485760 |

**[게시판 디자인/양식]**

| 항목 | portfolio · review | 나머지 |
|---|---|---|
| 갤러리 이미지 수 | 3 | (기본값) |
| 갤러리 이미지 폭 / 높이 | **640 / 480** | (기본값) |
| 이미지 폭 크기 | 1040 | 1040 |
| 페이지당 목록 수 | 12 | 15 |

> 상담 문의는 반드시 **비밀글: 무조건**, **DHTML 에디터: 해제** 로 두세요.
> 신청서 스킨이 일반 텍스트 입력을 쓰고, 개인정보가 다른 사람에게 보이지 않게 하는 설정입니다.

## 2단계. 자주하는 질문 (선택)

**게시판관리 > FAQ관리**
1. **FAQ 추가** → 제목 `자주하는 질문` 으로 저장
2. 목록에서 **상세보기** → **FAQ 상세내용 추가** 로 질문/답변 등록
   (예시 질문 4개는 `setup_boards.sql` 맨 아래에 있습니다. 문구를 복사해서 쓰시면 됩니다)

## 3단계. 이용약관 · 개인정보처리방침

**게시판관리 > 내용관리**
- `provision`(이용약관) 수정 → 내용에 `_content/provision.html` 붙여넣기
- `privacy`(개인정보처리방침) 수정 → 내용에 `_content/privacy.html` 붙여넣기
- 에디터 화면이면 "HTML" 또는 "소스" 모드로 바꾼 뒤 붙여넣으세요.

## 4단계. 문의 알림 메일

**환경설정 > 기본환경설정 > 게시판 글 작성 시 메일 설정**
- **메일발송 사용** 체크
- **최고관리자** 체크 (관리자 메일 주소로 새 문의 알림)
- 관리자 메일 주소가 실제 받는 주소인지 확인 (환경설정 > 기본환경설정 상단)

## 5단계. 확인

| 확인할 것 | 정상 모습 |
|---|---|
| 상단 메뉴의 각 게시판 | 디자인된 화면이 열림 ("존재하지 않는 게시판" 안내가 나오면 TABLE 이름 확인) |
| 상단 "상담 문의" 버튼 | 신청서(신청자 정보 · 공사 정보 · 개인정보 동의) 화면 |
| 로그아웃 후 상담 신청 1건 등록 | 목록에 자물쇠 + 이름 가운데 가림(홍*동) 으로 표시 |
| 관리자 로그인 후 그 글에 댓글 | 목록에 "답변완료" 표시 |
| 시공사례에 사진 넣어 글 1건 등록 | 목록에 4:3 썸네일, 메인 시공사례 영역에 표시 |
